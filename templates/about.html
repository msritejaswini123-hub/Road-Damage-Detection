THE TECHNOLOGY BEHIND THE INSIGHT

Computer vision, built for roads.

A clear, modular workflow that turns your model's actual detections into visual evidence.

VISION PIPELINE

Every result starts with your trained model.

RoadVision AI connects a Flask web app to an Ultralytics YOLO model you provide. It does not include pretrained road-damage weights or fabricate predictions.

Try an image
Road image
YOLO model
Detections
01

Computer vision

Image pixels are analyzed to locate visible road-surface damage. For each detection, the model supplies a class, confidence score, and bounding-box coordinates.

02

YOLO object detection

The adapter loads a trained Ultralytics YOLO weights file from ROAD_DAMAGE_MODEL. Predictions and annotated image overlays come directly from model output.

03

Deep learning

A detector learns patterns from labeled training images. The weights, dataset, accuracy, and class mapping are determined by the model you train and configure.

SUPPORTED CLASS LABELS

Road damage taxonomy

Recognized from model metadata

Longitudinal crackLengthwise surface cracking
D10
Transverse crackCracking across the road
D20
Alligator crackInterconnected fatigue cracking
D40
PotholeLocalized surface depression

Class names are taken from the loaded model. D00, D10, D20, and D40 labels are recognized when present in its metadata; other model classes remain visible by their original names.

GET STARTED

Connect your trained YOLO weights.

Install dependencies, point the app to your model file, then launch the Flask server.

pip install -r requirements.txt
$env:ROAD_DAMAGE_MODEL="C:\models\road_damage.pt"
python app.py
